# Dungeon-aas

Dungeon-aas — это проект из серии работ '-aas'. Является простым рогаликом на Laravel. На данный момент реализована backend-часть. Игрок путешествует по бесконечному подземелью, каждый раз выбирая одну из двух дверей. За дверью может оказаться монстр, сундук с золотом, лекарь, броня или пустая комната. Игра продолжается до гибели персонажа. Вся статистика сохраняется в профиль игрока.

## Структура проекта:

- **app/** — основная директория
    - **Constants/** — константы игры (вероятности и лимиты)
    - **Http/**
        - **Controllers/** — контроллеры авторизации, меню и игры
        - **Requests/** — реквесты для валидации
        - **Resources/** — API ресурсы для фронтенда

        - **Menu/** — сервисы для меню

## Геймплей

Dungeon-aas по сути простое пошаговое рогалик-приключение, где игрок исследует бесконечные комнаты подземелья, каждый раз принимая решения, какую из двух комнат выбрать. Цель: пройти как можно больше комнат и собрать максимум золота, оставаясь в живых. 

Игрок управляет персонажем, который последовательно заходит в комнаты подземелья. Каждая комната предлагает **случайное событие** из пяти возможных типов и подтипов внутри них. Игрок видит **два варианта** (левая или правая комната), выбирает один из них, после чего применяется эффект выбранной комнаты. Типы комнат скрыты от пользователя до выбора, а сами комнаты не повторяются: при генерации двух вариантов комнат они всегда будут разных типов. Игра заканчивается, когда здоровье персонажа падает до **0**. После окончания игры статистика сохраняется, и игрок может начать новое приключение. В лидербордах можно соревноваться с другими игроками по ключевым показателям: кол-во золота за всё время, кол-во комнат за всё время, макс. комнат за одну игру. Стоит заметить, что активная сессия только одна: при создании новой игры старая активная сессия удаляется.

### Характеристики персонажа

| Характеристика | Начальное значение | Максимум | Описание |
|---|---|---|---|
| **Здоровье** | 100 | 100 | Основной ресурс выживания. При достижении 0 игра заканчивается. |
| **Броня** | 0 | 50 | Снижает получаемый урон. Урон сначала поглощается бронёй, остаток переходит на здоровье. |
| **Золото** | 0 | ∞ | Накопленное за текущую игру золото. Влияет на итоговый счёт и рейтинг. |
| **Комнаты** | 0 | ∞ | Количество успешно пройденных комнат в текущей игре. |

### Типы комнат и их вероятности:

| Тип комнаты | Вероятность | Эффект |
|---|---|---|
| **Сундук** | 20% | Даёт золото |
| **Лекарь** | 20% | Восстанавливает здоровье |
| **Пустая комната** | 25% | Ничего не происходит |
| **Монстр** | 30% | Наносит урон |
| **Броня** | 5% | Увеличивает броню |

### Подтипы комнат и их эффекты:

#### Сундук – 20%

| Подтип | Вероятность | Эффект |
|---|---|---|
| Деревянный | 60% | Золото +10 |
| Железный | 20% | Золото +30 |
| Золотой | 15% | Золото +50 |
| Алмазный | 5% | Золото +100 |

#### Лекарь – 20%

| Подтип | Вероятность | Эффект |
|---|---|---|
| Травник | 40% | Здоровье +10 |
| Зелье | 30% | Здоровье +25 |
| Костоправ | 25% | Здоровье +50 |
| Анатом | 5% | Здоровье +100 |

#### Броня – 5%

| Подтип | Вероятность | Эффект |
|---|---|---|
| Кольчуга | 70% | Броня +25 |
| Железный доспех | 30% | Броня +50 |

#### Монстр – 30%

| Подтип | Вероятность | Урон |
|---|---|---|
| Шреккель | 60% | -25 здоровья |
| Тормин | 30% | -50 здоровья |
| Гросстройц | 10% | -70 здоровья |

#### Пустая комната – 25%

| Подтип | Вероятность | Эффект |
|---|---|---|
| Пустота | 100% | Ничего не происходит |

В дальнейшем планируется добавление других типов и подтипов комнат.

## Установка Dungeon-aas

Клонировать репозиторий:

```bash
git clone https://github.com/AleksandrSadouski/Dungeon-aas.git
cd Dungeon-aas
```

Установить зависимости:

```bash
composer install
```

Настроить окружение:

```bash
cp .env.example .env
```

В файле .env указать настройки базы данных:

```bash
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=dungeon
DB_USERNAME=root
DB_PASSWORD=
```

Сгенерировать ключ и запустить миграции:

```bash
php artisan key:generate
php artisan migrate
```

Запустить сервер:

```bash
php artisan serve
```

Сервер будет доступен по адресу: http://127.0.0.1:8000

## Тестирование через Postman

1. Регистрация:
```bash
   POST /api/auth/register
   Body: { 
    "name": "Sashok", 
    "password": "XXXXXXXX",
    "password_confirmation": "XXXXXXXX"}
   → сохранить token из ответа
```

   или

   Вход:
```bash
   POST /api/auth/login
   Body (JSON): {
    "name": "Sashok",
    "password": "XXXXXXXX"}
   → сохранить token из ответа
```

2. Создать игру:
```bash
   POST /api/menu/game
   Header: Authorization: Bearer {token}
   → сохранить session_id из ответа
```

3. Открыть комнату:
```bash
   POST /api/game/step
   Header: Authorization: Bearer {token}
   Body: { "choice": "left" } или Body: { "choice": "right" }
```

4. Продолжить игру (если уже есть сессия, иначе вернёт ошибку 400):
```bash
   GET /api/menu/game
   Header: Authorization: Bearer {token}
```

5. Показать статистику игрока:
```bash
   GET /api/menu/stats
   Header: Authorization: Bearer {token}
```

6. Лидерборд по параметру:
```bash
   GET /api/menu/leaderboard?type_top=[kol_rooms, kol_gold, max_rooms]
   Header: Authorization: Bearer {token}
```

7. Переименовать игрока:
```bash
   PATCH /api/menu/name
   Header: Authorization: Bearer {token}
   Body: { "new_name": "Andala" }
```

8. Удалить игрока:
```bash
   DELETE /api/menu/delete
   Header: Authorization: Bearer {token}
   Body: { "password": "XXXXXXXX" }
```

9. Выйти:
```bash
   DELETE /api/menu/logout
   Header: Authorization: Bearer {token}
```

При смерти игрока is_active становится 0, статистика обновляется.
